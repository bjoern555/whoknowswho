# whoknowswho
## Start

```
npm install
npm start
```

Open `http://localhost:3001` — or use [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/do-more-with-tunnels/trycloudflare/) for a public URL anyone can scan:

```
cloudflared tunnel --url http://localhost:3001
```

Paste the tunnel URL into the **⚙ host settings** field on the page to update the QR code.
